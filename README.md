# Web Time Warp

Build a modern, highly interactive website called “Internet Time Machine”.

Core Concept

Create an interactive website that lets users explore how the internet and digital culture evolved across different eras.

The user should be able to select a year or era and experience a visual recreation of what the web looked and felt like during that period.

The experience should feel like traveling through time on the internet, not like a normal informational website.

Main Time Periods

Include a horizontal interactive timeline with:

1990–1995 — The Early Web

1996–2000 — Web 1.0

2001–2005 — The Dot-Com Era

2006–2010 — Social Media Begins

2011–2015 — Smartphone & Social Era

2016–2020 — Modern Web

2021–Present — AI Era

Future — Experimental Future Web

Allow users to drag, scroll, or click through the timeline.

Homepage

Create a cinematic landing page with:

Title:
INTERNET TIME MACHINE

Subtitle:
“Travel through the evolution of the web.”

Add a large interactive time machine / digital portal visual in the center.

Primary button:
ENTER THE TIME MACHINE

Secondary button:
EXPLORE TIMELINE

Use subtle animations such as glowing particles, scanlines, digital transitions, and smooth scrolling.

Time Travel Experience

When the user selects a year, transition the entire interface into the visual style of that era.

For example:

1990s

Grey/white backgrounds

Simple HTML-style layouts

Pixelated icons

Old-school hyperlinks

Basic tables

Monospace fonts

“Under Construction” elements

CRT-inspired effects

2000s

Web 2.0 aesthetics

Glossy buttons

Rounded panels

Early social-network inspired layouts

Blog-style interfaces

Classic search-engine-inspired design

2010s

Flat design

Social-media-inspired cards

Mobile-first layouts

Large hero sections

App-style interfaces

2020s

Minimal modern UI

Dark/light mode

AI assistants

Real-time dashboards

Glassmorphism used subtly

Future

Create an experimental futuristic interface with:

Holographic-style panels

AI interfaces

Spatial navigation

Dynamic data visualizations

Futuristic typography

Do not copy real websites or use copyrighted logos/assets. Create original interfaces inspired by the design trends of each era.

“What Changed?” Section

For every era, show an interactive comparison containing:

Design

Technology

Browsers

Search

Social media

Communication

Devices

Popular web trends

Use animated cards and expandable information panels.

“Internet Evolution” Visualization

Create an interactive visualization showing the evolution:

Static HTML
→ Dynamic Websites
→ Web 2.0
→ Social Media
→ Mobile Web
→ Cloud
→ AI
→ Future Web

Users should be able to click each stage to learn more.

Interactive Browser

Add a simulated browser window that changes according to the selected era.

Include:

Address bar

Back/forward buttons

Reload button

Browser tabs

Fake webpage content appropriate to the selected year

The browser itself should visually evolve as the user travels through time.

“On This Year” Panel

When selecting a year, display:

Major internet developments

Popular technologies

Typical devices

Web design trends

Communication methods

Internet culture

Use concise cards rather than large blocks of text.

Time Machine Controls

Add a persistent control at the bottom of the screen:

[ ◀ Previous Era ] [ YEAR / ERA ] [ Next Era ▶ ]

Also include:
Jump to Year

with a slider from 1990 to 2026.

Visual Design

The overall website should feel like a premium interactive technology experience.

Use:

Dark futuristic base theme for the main interface

Neon accents

Glassmorphism

Subtle gradients

Smooth animations

Micro-interactions

Depth and layered UI

Responsive design

However, when the user enters an older era, the interface itself should transform to match that era.

Avoid excessive animations that make the website difficult to use.

Sound

Do not autoplay sound.

Optionally include a small sound toggle that can enable subtle era-appropriate UI sounds.

Extra Feature — “Random Time Travel”

Add a button:

TAKE ME SOMEWHERE RANDOM

Clicking it randomly selects an era and transitions the user there.

Extra Feature — “Future Mode”

Allow the user to select 2050 and explore a fictional concept of what the internet might look like.

Clearly label this as:
SPECULATIVE FUTURE CONCEPT

Do not present predictions as facts.

Technical Requirements

Build this as a responsive web application.

Use:

React

TypeScript

Tailwind CSS

Modern component architecture

Smooth CSS/JS animations

Local state for the timeline

Reusable components

Clean and maintainable code

Make the application work properly on:

Desktop

Tablet

Mobile

Use mock/static data for historical information initially, structured so that it can easily be replaced with a database/API later.

Important UX Requirement

The website should NOT feel like a normal timeline website.

The main experience should be:

Choose a year → activate the time machine → watch the interface transform → explore the web of that era.

Make transitions between eras visually satisfying and memorable.

Final Quality

Make the website feel like a combination of:

Interactive museum

Digital history archive

Futuristic time machine

Web design showcase

Prioritize visual quality, interaction, responsiveness, and a strong “wow” factor.

Start by building the complete homepage and core time-travel experience, then implement the era-specific interfaces and interactive timeline.
